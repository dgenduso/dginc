# Claude Code Instructions — Consulting Website

Use `WEBSITE_BRIEF.md` as the product, content, and design source of truth.

## Your assignment
Implement a compelling website for an Organizational Innovation & Transformation consulting firm. It is **consulting-first**, not a SaaS website. Deliver a polished, responsive homepage and reuse the repository's existing conventions.

## Before coding
1. Inspect the repository: framework, package manager, existing design system, routes, styling, assets, components, and scripts.
2. Summarize your implementation plan briefly. If branding/contact information is missing, use obvious, centralized configuration placeholders rather than fabricating details.
3. Respect existing functionality and preserve existing valuable content.

## Build sequence
1. Create/refine the design language and page shell (navigation, footer, typography, spacing, responsive behavior).
2. Implement the eight homepage sections in `WEBSITE_BRIEF.md` with high-quality layout and near-final copy.
3. Build a memorable, accessible iterative methodology visualization emphasizing continuous learning and cross-functional work, without heavy graph libraries unless already present.
4. Ensure functional navigation and CTAs; avoid fake buttons or links to missing pages.
5. If time and repo support allow, add robust Services and Our Approach pages.
6. Verify mobile, tablet, and desktop layouts, keyboard accessibility, metadata, and reasonable performance.
7. Run available validation commands and summarize changes and remaining placeholders.

## Content discipline
- Preserve the strategy and key wording in `WEBSITE_BRIEF.md`; minor editing for clarity and brevity is welcome.
- Do not suggest the consultancy is limited to product-team transformation.
- Distinguish products, services, and customer experiences.
- Do not market the future operating system as a current commercial product.
- No made-up clients, testimonials, metrics, team members, contact addresses, or case studies.
- Avoid generic AI visual clichés and generic marketing hype.
- Aim for a premium, credible transformation consultancy aesthetic with distinctive methodology visualization.
